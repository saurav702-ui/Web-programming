# Week 11 — React Practice Lab

A React practice website for JSX, props, state, and event handling.

## Included
- React foundations quiz with feedback and score
- Reusable `StudentCard` component using props
- Seven state/event exercises:
  1. Counter
  2. Show/hide text
  3. Like button
  4. Background changer
  5. Live character counter
  6. Simple login form (demo only)
  7. Todo list with delete

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local address shown in the terminal.

## Build for deployment
```bash
npm run build
```
The production files will be created in `dist/`.
