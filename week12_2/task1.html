City weather search

Open-Meteo provides weather data without an API key. Search a city to load its current conditions and seven-day forecast.

How the effect works

  • Geocoding converts the city name into latitude and longitude.
  • The forecast request uses those coordinates.
  • An AbortController cancels an earlier request when a new search begins.
  • The page displays loading, success and error states.
