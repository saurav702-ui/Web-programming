# Week 12.2 — React Effects & useEffect

A standalone multi-page workshop in the cream / forest-green theme used in the previous assignments.

## Files
- `index.html` — central hub linking all exercises
- `task1.html` — Weather Dashboard (Open-Meteo geocoding and forecast API)
- `task2.html` — GitHub User Lookup (GitHub Users API)
- `task3.html` — Page title sync, JSONPlaceholder user fetch, stopwatch
- `task4.html` — dependency patterns, timer cleanup, race condition simulation, derived state, guarded update
- `task5.html` — 12-question sprint quiz and 8 concept checks
- `assets/style.css` — shared design theme

## Run
Open `index.html` in a browser. The API exercises need an internet connection. Geolocation works on localhost or HTTPS and requires browser permission.

## GitHub Pages
Upload the complete `week12_2` folder into the root of your repository. If your existing Vite workflow publishes only the `dist` directory, put this folder inside the Vite project's `public` directory instead:
`public/week12_2/`

Then visit:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/week12_2/`

The folder contains plain HTML pages and shared CSS; no npm install or build is required for these pages.
